About MovieBook

A simple full-stack movie ticket booking application for a college software engineering project.

🎬

Purpose

MovieBook demonstrates a complete booking workflow: registration, login, movie discovery, nearby theatre search, show selection, ticket booking, booking history and cancellation.

⚙️

Technology

Python Flask is used for the web server, Jinja2 for templates, HTML/CSS/JavaScript for the interface and SQLite for persistent project data.

📍

Location

The location module uses browser geolocation and a live OpenStreetMap-based cinema search, with a local theatre database available as a fallback.
